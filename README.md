# Documentación del Proyecto PokéDex - Tutorial de Creación de Cuenta y Configuración Inicial

## Contexto del Proyecto
La compañía **Pueblo Paleta Inc.** contrató a la empresa externa **PumasLab** para el diseño visual y desarrollo de la aplicación **PokéDex**, una plataforma interactiva que permite a los usuarios explorar especies de Pokémon y consultar sus características detalladas[cite: 1]. Este documento forma parte de la guía de actividades orientada al despliegue seguro de la aplicación en una plataforma de nube pública[cite: 1, 5].

---

## 1. Proceso Paso a Paso para la Creación de la Cuenta en la Nube Pública (Microsoft Azure)

Para cumplir con los pre-requisitos de despliegue establecidos por la compañía, se seleccionó **Microsoft Azure** a través del programa académico institucional. A continuación se detalla el procedimiento completo:

1. **Registro e Ingreso a la Plataforma:**
   - Dirigirse al portal oficial de Microsoft Azure utilizando una cuenta institucional o académica vinculada al programa **Azure for Students** o **Azure for Students Starter**.
   - Completar el formulario de activación de la suscripción gratuita para estudiantes, validando la identidad y aceptando los términos del servicio.

2. **Acceso al Portal de Administración:**
   - Una vez activa la suscripción, ingresar al portal principal en [portal.azure.com](https://portal.azure.com).
   - Verificar en el panel superior derecho que se encuentre activa la suscripción correcta (ej. *Azure for Students Starter*).

---

## 2. Configuración Inicial del Repositorio en GitHub

Como requisito fundamental para la integración continua y el despliegue automatizado, se estructuró el repositorio del proyecto:

1. **Creación del Repositorio:**
   - Iniciar sesión en la plataforma **GitHub**.
   - Crear un nuevo repositorio público o privado con el nombre exacto de **`pokedex`**[cite: 1, 5].

2. **Clonación y Preparación del Entorno Local:**
   - Clonar el repositorio en el equipo local utilizando la terminal mediante el comando de clonación de Git.
   - Integrar el código fuente provisto por el caso de estudio correspondiente a la aplicación PokéDex desarrollada en Angular.
   - Abrir el directorio del proyecto en un entorno de desarrollo integrado como **Visual Studio Code (VS Code)** para gestionar los archivos de configuración y control de versiones.

---

## 3. Uso de la Herramienta StackEdit para la Gestión de Documentos Markdown

Para cumplir con el requisito de familiarización y uso de herramientas profesionales de edición Markdown (requisito número 5 de la guía):
- Se utilizó la aplicación web **StackEdit** (`https://stackedit.io/`) para redactar, previsualizar y validar la estructura sintáctica de los archivos de documentación del proyecto (`README.md` y `Despliegue.md`).
- Esto garantiza que las tablas, bloques de código, negritas y encabezados se rendericen correctamente y cumplan con los estándares de calidad técnica exigidos por Pueblo Paleta Inc.
